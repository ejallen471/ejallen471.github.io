# Personal Website

This repo contains the files for my website.

The site is available at [ejallen471.github.io](https://ejallen471.github.io).

## Structure

```text
index.html                    Homepage
pages                         Main pages (About, CV, Baking, Diving, Reading, Projects)
pages/baking/recipes          Individual recipe pages
projects                      Project pages and documents
assets                        Images, videos and PDFs
stylesheets/site.css          Shared styling
stylesheets/baking.css        Baking page styling
scripts/home.js               Homepage interactions
scripts/diving_map.js         Diving map
```

## Editing

Edit the HTML, CSS or JavaScript directly.

To preview the site locally, run this command from the repository root.

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` in a browser.

Alternatively, you can open the `.html` files directly.
